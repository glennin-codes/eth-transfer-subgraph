# ETH and USDC Transfer Subgraph

This subgraph indexes Transfer events for both native Ethereum (ETH) and the USDC stablecoin on the Ethereum mainnet.

## Overview

The primary goal of this subgraph is to provide a unified data source for tracking value transfers of ETH and USDC. It listens for:

1.  **Native ETH Transfers:** Simulated `Transfer(address,address,uint256)` events generated by The Graph for value transfers between Ethereum addresses.
2.  **USDC Transfers:** Standard ERC-20 `Transfer(address,address,uint256)` events emitted by the official USDC contract (`0xa0b86991c6218b36c1d19d4a2e9eb0ce3606eb48`).

## Schema

The subgraph stores transfer data in a single entity type:

- `Transfer`:
  - `id`: Unique identifier (Transaction Hash + Log Index)
  - `from`: Sender address
  - `to`: Recipient address
  - `value`: Amount transferred (in wei for ETH, smallest unit for USDC)
  - `asset`: String identifier ("ETH" or "USDC")
  - `blockNumber`: Block number of the transfer
  - `blockTimestamp`: Timestamp of the block
  - `transactionHash`: Hash of the transaction

## Development & Deployment

1.  **Install Dependencies:**
    ```bash
    npm install
    # or
    yarn install
    ```
2.  **Generate Code:** Compile the schema and generate AssemblyScript types.
    ```bash
    graph codegen
    ```
3.  **Build Subgraph:** Compile the mappings to WASM.
    ```bash
    graph build
    ```
4.  **Deploy:** Deploy to the Graph Network (Studio or Hosted Service).

    ```bash
    # Authenticate (if needed)
    graph auth --studio <YOUR_DEPLOY_KEY>

    # Deploy
    graph deploy --studio <YOUR_SUBGRAPH_NAME>
    ```

    Replace `<YOUR_DEPLOY_KEY>` and `<YOUR_SUBGRAPH_NAME>` with your actual key and subgraph name/slug.
